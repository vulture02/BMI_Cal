# 🏋️ BMI Calculator

A simple and responsive Body Mass Index (BMI) calculator built with React, Tailwind CSS, and JavaScript. The app allows users to input their weight and height to calculate their BMI and get an instant assessment of their health status.

## 📌 Description

This BMI Calculator helps users determine if their weight is within a healthy range based on their height and weight. It provides a user-friendly interface with clear feedback using React for the logic and Tailwind CSS for responsive styling.

## 🛠️ Tech Stack

- **React** – Frontend library for building the user interface
- **Tailwind CSS** – Utility-first CSS framework for styling
- **JavaScript** – For BMI calculation logic

## ✨ Features

- Input weight and height to calculate BMI
- BMI result with corresponding health status (Underweight, Normal, Overweight, Obese)
- Responsive design with Tailwind CSS
- Simple and clean user interface
